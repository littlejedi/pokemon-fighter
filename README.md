# KANTO FIGHTERS · 关都格斗大会

可直接在浏览器运行的初代宝可梦题材 2D 格斗游戏。原生 JavaScript + Canvas，高清训练家与宝可梦贴图、三个独立的道馆背景，无运行时依赖。

## 运行

需要 Node.js 18 或以上，无需安装依赖。

```sh
npm run dev
```

打开 http://localhost:5173 。`npm run build` 生成静态站点至 `dist/`，`npm run preview` 预览构建结果，`npm test` 运行战斗逻辑测试。

## 操作

- A / D：移动；W：跳跃；S：防御，减免 80% 伤害
- J / K：普通拳击 / 踢击
- L：属性必杀，消耗 20 点能量
- I：代表宝可梦召唤，消耗 100 点能量
- P：暂停；Enter：重新开始
- 手机支持触屏按键

11 位训练家包括 8 位关都馆主、小智、青绿与大木博士，四天王已从可选阵容移除。速度、力量、普通攻击距离、必杀冷却和弹速依角色不同；草攻击减速，毒攻击附带持续伤害，超能力攻击延长硬直。每位训练家拥有对应的伙伴和召唤招式。

当前为单人对战电脑、三局两胜的可玩原型；提供三种场地主题、图鉴、操作指南、音效开关和全屏。人物采用 Pokémon Masters EX 高清透明立绘及双姿态切换，宝可梦采用官方原画，背景采用内置 image_gen 生成的游戏风格场景贴图。使用 1920×996 画布和平滑采样，包含落地阴影、呼吸起伏、属性弹道和伙伴召唤效果。全部 48 张贴图本地预加载后开放对战。详见 [素材来源和生成提示词](assets/README.md)。字体联网可用时加载 Google Fonts，离线使用系统回退字体。

非官方同人项目，仅供学习交流。

## 本轮动画升级进度

已实现图鉴体型比例、3.2 秒召唤特写、伙伴入场/蓄力/释放/离场、特写暂停计时，以及带起手/命中/收招的攻击判定。

**侧身序列帧美术尚未完成**：内置图像生成服务连续网络错误，当前人物仍临时使用原高清立绘。不得将时序测试通过视作肢体动画完成。全套素材验收使用 `npm run audit:animation`，当前会报告缺失项。详见 [五项优化进度](docs/animation-progress.md)。

### 三人骨骼图集与录屏演示

小智、大木博士、坂木使用侧身分层 SVG + 双骨骼 IK 制作的透明 PNG 图集，每人 118 帧、9 组动作。默认对手为大木博士；选择大木博士时对手为小智。两次新角色 imagegen 请求失败后，按用户要求采用此方法。其余角色暂保留原素材。

- 点击「演示对决」：自动循环小智与大木博士对战；每轮双方都有拳、踢、普通必杀、伙伴召唤，使用实际命中和特写流程。
- 点击「录屏视图」，或打开 `/?demo=1&clean=1`：隐藏大厅和控制栏，保留 16:9 黑边画面。双方展示招式后继续交锋，直到大木博士零血倒下；胜利画面停留 7 秒后才重置血量和能量。
- `P` 暂停/继续，`Esc` 退出录屏视图。鼠标移到画面底部可显示「从头播放」等按钮。声音默认关闭，可先退出录屏视图，通过 ♪ 开启。
- 本地 `/ash-lab.html` 支持小智动作逐帧检查、骨骼显示与图集下载。
- 重建：`npm run build:rig -- 0`（小智）、`-- 14`（大木）、`-- 8`（坂木）。需要 Sharp；支持本地安装或 `ASH_SHARP_PATH`，当前环境使用 Codex 自带依赖。
- 可编辑绘制与骨架：`src/ash-rig.js`、`src/adult-rig.js`；分层源与姿态对照：`assets/rigs/{ash,oak,giovanni}/`。重建会撤销对应图集的视觉验收标记，需要重新检查。

### 街机演示流程更新

演示现在先播放约 4.8 秒选人巡游，展示 11 位训练家并锁定小智和大木博士，再播放 3、2、1、FIGHT 语音与画面。开场约 8 秒交锋在每轮随机改变拳脚顺序、站位、进退及跳跃，之后按时展示双方必杀与伙伴召唤，继续打到大木博士被击倒，再进入胜利展示并循环。

背景音乐直接播放初代 Game Boy 游戏的原版战斗录音，胜利时切换原版训练家胜利曲。两个 MP3 均保存在 `assets/audio/`；来源和时长见 `assets/audio/recordings.json`。此前的音符合成版本已停用，旧音谱仅作存档。倒数仍为本地 WAV，运行时不依赖外部音乐服务。

直接打开演示链接时，点击「开启声音并从选人开始」可解锁浏览器声音并从头演示。底部有声音开关；P 暂停画面与音乐，退出演示会停止音乐。开启声音后该提示按钮自动隐藏，不影响录屏。


胜利演出：大木博士血条归零 → 2.2 秒 K.O. 倒地 → 7 秒小智与皮卡丘胜利画面。胜利使用 `assets/trainers/0_2.png` 和 `assets/pokemon/25.png` 的经典贴图，包含入场、皮卡丘跳跃、彩纸、WINNER 标题与「就决定是你了！」台词。暂停会冻结胜利时间和音乐。
